# 🎓 UoPeople CS Lab CLI

A CLI tool that demonstrates Data Structures & Algorithms from UoPeople CS courses.

## Courses Covered
- CS 1102 - Programming 1 (Python)
- CS 1103 - Programming 2 (OOP)
- CS 3303 - Data Structures
- CS 3304 - Analysis of Algorithms
- CS 2203 - Databases

## Data Structures Implemented
- Stack (LIFO) - Undo / Back button
- Queue (FIFO) - Printer queue / BFS
- Linked List - Dynamic insert/delete O(1)
- Binary Search Tree - Search O(log n)
- Hash Table - O(1) lookup (like Guardian blocklist)
- Graph - BFS vs DFS
- Sorting - Bubble O(n²) vs Quick Sort O(n log n)

python cs_lab.py
